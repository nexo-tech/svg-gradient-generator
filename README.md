# SVG Gradient Generator

A modern web application for generating beautiful SVG gradients with cloud patterns and distortions, perfect for blog post covers.

## Features

- Generate sophisticated gradients with cloud-like patterns
- Adjust gradient colors using color pickers
- Control cloud density and distortion levels
- Download generated gradients as SVG files
- Responsive design that works on all devices

## How to Use

1. Open `index.html` in your web browser
2. Use the color pickers to select your desired gradient colors
3. Adjust the cloud density slider to control the number of cloud patterns
4. Use the distortion level slider to add dynamic distortion effects
5. Click "Generate Gradient" to create a new gradient
6. Click "Download SVG" to save your gradient as an SVG file

## Technical Details

The application uses:
- HTML5 for structure
- CSS3 for styling
- JavaScript for gradient generation
- SVG filters for cloud patterns and distortions
- Modern browser APIs for file downloads
